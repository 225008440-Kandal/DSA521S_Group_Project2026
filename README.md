## Description
A menu-driven Java program that simulates a campus service centre.
It applies the core linear data structures (array, linked list, stack, queue)
and the four main sorting algorithms, all implemented from scratch
(without Java's built-in collection or sort classes).

## Files
| File | Part | Description |
|------|------|-------------|
| Student.java | – | Student record (number, name, service, time) |
| StudentQueue.java | A1 | Waiting line (Queue, FIFO) |
| StudentLinkedList.java | A2 | Student records (Singly Linked List) |
| PostfixStack.java | A3 | Stack for postfix expression evaluation |
| DailyStatistics.java | A4 | Daily statistics stored in an array |
| SortingAlgorithms.java | B | Selection, Insertion, Merge, Quick sort |
| Experiment.java | C | Compares sorts by counting comparisons |
| Main.java | D | Integrated menu connecting all parts |

## How to Run
1. Make sure the JDK is installed (`java -version`).
2. Open a terminal in the project folder.
3. Compile all files:
javac *.java
4. Run the program:
java Main
5. Use the menu (type a number and press Enter). Type `0` to exit.

## Menu Options:
1.Add student to waiting queue (enqueue)
2.Serve next student (dequeue)
3.Show waiting queue
4.Add a student record (linked list)
5.Show all student records
6.Evaluate a postfix expression
7.Add a daily service time
8.Show daily statistics
9.Run sorting experiment
10.Exit
